# IoT-Based NLR and MLR Monitoring System

## Project Overview

This project is an academic prototype designed to monitor Neutrophil-to-Lymphocyte Ratio (NLR) and Monocyte-to-Lymphocyte Ratio (MLR) using blood-smear images.

The system uses an Arduino Uno and OV7670 camera to capture images. Python, OpenCV, and YOLO are used for blood cell detection and ratio calculation.

## Technologies Used

* Arduino Uno
* OV7670 Camera
* Python
* OpenCV
* YOLO
* Java
* OLED Display

## Workflow

1. Prepare a blood smear sample on a glass slide.
2. Capture the image using the OV7670 camera.
3. Transfer the image to the computer.
4. Process the image using Python and OpenCV.
5. Detect neutrophils, lymphocytes, and monocytes using YOLO.
6. Calculate NLR and MLR.
7. Display the calculated values.

## Objectives

* Develop a low-cost monitoring prototype.
* Capture and process blood-smear images.
* Detect and count blood cells.
* Calculate NLR and MLR.

## Disclaimer

This is an academic prototype for research and monitoring purposes. It is not a validated medical diagnostic device.
